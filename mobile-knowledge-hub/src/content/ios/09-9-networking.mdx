      ### URLSession with async/await

      `data(for:)` returns `(Data, URLResponse)` asynchronously. Paired with `JSONDecoder`,
      a single call eliminates `dataTask(with:)` nesting. Use `.task { }` for view-scoped
      networking — it cancels on disappear while `.onAppear { Task }` does not.

      ```swift
      final class APIClient {
          private let session: URLSession
          private let decoder = JSONDecoder()
          init(session: URLSession = .shared) { self.session = session }

          func fetch<T: Decodable>(_ request: URLRequest) async throws -> T {
              let (data, response) = try await session.data(for: request)
              guard let httpResponse = response as? HTTPURLResponse else {
                  throw APIError(message: "Invalid response", code: -1)
              }
              switch httpResponse.statusCode {
              case 200...299: return try decoder.decode(T.self, from: data)
              case 401: throw APIError(message: "Unauthorized", code: 401)
              default: throw APIError(message: "Error", code: httpResponse.statusCode)
              }
          }
      }
      ```

                               error -> catch

      ### Alamofire — RequestInterceptor Pattern

      Alamofire's `RequestInterceptor` combines `AdaptHandler` (inject headers) and
      `RetryHandler` (retry on 401 with token refresh).

      ```swift
      import Alamofire

      final class AuthInterceptor: RequestInterceptor {
          func adapt(_ urlRequest: URLRequest,
                     for session: Session,
                     completion: @escaping (Result<URLRequest, Error>) -> Void) {
              var request = urlRequest
              request.setValue("Bearer \(TokenManager.current)",
                               forHTTPHeaderField: "Authorization")
              completion(.success(request))
          }

          func retry(_ request: Request,
                     for session: Session,
                     dueTo error: Error,
                     completion: @escaping (RetryResult) -> Void) {
              guard request.response?.statusCode == 401 else {
                  return completion(.doNotRetry)
              }
              Task {
                  TokenManager.current = try await AuthService.shared.refreshToken()
                  completion(.retry)
              }
          }
      }

      let session = Session(interceptor: AuthInterceptor())
      session.request("https://api.example.com/users")
             .validate()
             .responseDecodable(of: [User].self) { response in
                 // handle response.result
             }
      ```

      ### WebSocket and Reachability

      URLSessionWebSocketTask with async/await receive loop.

      ```swift
      final class WebSocketManager: NSObject, URLSessionWebSocketDelegate {
          private var task: URLSessionWebSocketTask?

          func connect(to url: URL) {
              let session = URLSession(configuration: .default, delegate: self, delegateQueue: nil)
              task = session.webSocketTask(with: url)
              task?.resume()
              receiveMessage()
          }

          private func receiveMessage() {
              task?.receive { [weak self] result in
                  guard case .success(let message) = result else { return }
                  if case .string(let text) = message { print(text) }
                  self?.receiveMessage() // re-arm
              }
          }

          func send(_ text: String) async throws {
              try await task?.send(.string(text))
          }
      }
      ```

      <Callout title="Never Block the Main Thread with Networking">
        URLSession's async methods return on a background queue by default. Wrap UI updates in
        `@MainActor` on your ViewModel methods. Always use `.task { }` for view-scoped
        networking to get automatic cancellation on view disappear.
      </Callout>

      ### Common Pitfalls

      **Missing cancellation**: A `Task` from `.onAppear` keeps running after the view deallocates,
      updating stale references. **Decoding without error context**: Log raw response data
      alongside decoding errors — `DecodingError.codingPath` alone is unhelpful. **Ignoring
      conditional GET**: ETag/Last-Modified revalidation reduces bandwidth but URLSession's
      URLCache does not send conditional headers automatically.

      ### iOS-Specific Insight

      URLSession sits on CoreFoundation's network stack — no serialization bridge or JS
      translation layer. On A-series and M-series chips, TLS 1.3 handshakes offload to the
      hardware crypto engine. This makes direct URLSession 30-50% more efficient per request
      than platform-channel networking in cross-platform frameworks.

      ### Cross-Platform Comparison

      Android's Retrofit is interface-based with annotations (`@GET`, `@POST`). Alamofire is
      function-based with method chaining. Flutter's Dio has interceptor pipelines similar to
      Alamofire. Apple's Codable is unique — encoding/decoding is a protocol conformance, not
      annotation processing, eliminating the code-generation step both Moshi and
      `json_serializable` require.
