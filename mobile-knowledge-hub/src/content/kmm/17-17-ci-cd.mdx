      ### Building KMP in CI

      KMP CI builds two distinct artifact types: an Android AAR (via Gradle) and
      an iOS XCFramework (Gradle, then linked by Xcode). A **matrix build** with
      separate jobs for Android and iOS is the standard approach — Android on
      Ubuntu, iOS on macOS.

      ```yaml
      # .github/workflows/kmp-ci.yml
      name: KMP CI
      jobs:
        android:
          runs-on: ubuntu-latest
          steps:
            - uses: actions/checkout@v4
            - uses: actions/setup-java@v4
              with: { java-version: "17", distribution: "temurin" }
            - run: ./gradlew :shared:assembleRelease :shared:allTests

        ios:
          runs-on: macos-14
          steps:
            - uses: actions/checkout@v4
            - uses: actions/setup-java@v4
              with: { java-version: "17", distribution: "temurin" }
            - run: ./gradlew :shared:linkDebugFrameworkIosArm64 :shared:linkDebugFrameworkIosSimulatorArm64
            - run: |
                cd iosApp && xcodebuild -scheme iosApp \
                  -sdk iphonesimulator -destination 'platform=iOS Simulator,name=iPhone 15' build
      ```

      ### Gradle Tasks for CI

      ```yaml
      # Key CI targets
      ./gradlew :shared:assembleRelease        # Android AAR (with ProGuard)
      ./gradlew :shared:allTests               # Tests on ALL targets
      ./gradlew :shared:linkReleaseFrameworkIosArm64   # iOS device framework
      ./gradlew :shared:linkReleaseFrameworkIosSimulatorArm64  # iOS simulator
      ```

      <Callout title="macOS CI Requirement">
        iOS target compilation requires macOS. Use `macos-14` (Apple Silicon)
        runners. Android builds on `ubuntu-latest` are cheaper and faster.
        GitHub Actions, Circle CI, and Codemagic all support macOS runners.
      </Callout>

      ### Publishing

      KMP libraries publish to **Maven Central** (Android AAR) and as
      **XCFramework** (iOS via SPM or direct embedding).

      ```yaml
      ./gradlew :shared:publishAllPublicationsToMavenCentral   # Android AAR
      ./gradlew :shared:assembleSharedReleaseXCFramework        # iOS framework

      # SPM distribution references the XCFramework binary:
      # binaryTarget(name: "Shared", path: "Shared.xcframework")
      ```

      ### Codemagic — Specialized KMP CI

      Codemagic offers KMP-specific pipelines with Gradle/Xcode caching (first
      build ~15 min, cached ~3 min on Apple Silicon runners).

      ```yaml
      # codemagic.yaml (excerpt)
      workflows:
        kmp-pipeline:
          instance_type: mac_mini_m2
          environment:
            vars:
              GRADLE_OPTS: -Dorg.gradle.daemon=true -Dorg.gradle.parallel=true
          scripts:
            - ./gradlew :shared:allTests
            - ./gradlew :androidApp:assembleRelease
            - ./gradlew :shared:linkReleaseFrameworkIosArm64
            - ./gradlew :shared:linkReleaseFrameworkIosSimulatorArm64
      ```

      ### Version Management

      ```yaml
      # gradle.properties — single source of truth
      kmpVersion=2.1.0
      # Accessible in build.gradle.kts via project.findProperty("kmpVersion")
      ```

      ### KMP Insight

      KMP CI is native Android CI plus native iOS CI in parallel. The shared
      Kotlin source produces platform binaries through the same Gradle build.
      CI does not need to "know" about KMP — it runs the same Gradle tasks
      as any native project. Complexity lives in coordinating artifact versions
      across platforms.
